Sponsor logos
=============

Drop each sponsor's logo into this folder using the exact filename below.
Accepted extensions (checked in this order): .svg, .png, .webp, .jpg, .jpeg
Transparent PNG or SVG is best. Until a file exists, the sponsor's name shows
as a styled text fallback.

Tiers are defined in theme/page-sponsors.php ($sponsor_tiers).

Presenting Sponsor
  sac-and-fox-casino.(png|svg|...)     -> Sac and Fox Nation Casino

King Boar Sponsors
  tatanka-ranch.(png|svg|...)          -> Tatanka Ranch
  five-star-bbq.(png|svg|...)          -> Five Star BBQ

Big Boar Sponsors
  genesis.(png|svg|...)                -> Genesis
  jim-hodgens.(png|svg|...)            -> Jim Hodgens

Trophy Hog Sponsors
  five-tool-management.(png|svg|...)   -> Five Tool Management
  ds-specialty-house.(png|svg|...)     -> D's Specialty House

To add a website link for a sponsor, set its 'url' in $sponsor_tiers
(theme/page-sponsors.php).
